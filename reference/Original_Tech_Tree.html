节点连接是什么意思？

线条主要表示更顺手的养成顺序和建议依赖，并不等同于游戏官方强制解锁条件。例如战甲配置优化可以与段位提升同时进行。选择节点后可查看具体说明。

交互快捷方式

拖拽空白画布平移，滚轮或 +/- 缩放；点击分支名称快速聚焦；点击节点打开任务详情；在行动列表中筛选和安排计划。手机支持单指平移和双指缩放。

数据与目标

资源库存、节点状态、行动步骤、个人笔记和日志都会自动保存在这台设备的浏览器。换浏览器或清理站点数据可能丢失，请及时导出 JSON 备份。
