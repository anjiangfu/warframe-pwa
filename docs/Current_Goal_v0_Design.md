# 通用目标助手 v0：设计与实施清单

2026-10-18。起点8e0f1547a2b7d1226aeba2a38d7f590c9fed05ff，干净分支m1b/current-goal-assistant。用户在审阅聊天确认方向、补充进度并明确“继续”；这次为独立功能授权，不扩展M0自动返修。原17项输入不变。

方案比较：逐把增加百科不能解决已完成内容仍被推荐；全面规则引擎超出本轮范围。采用现有LocalProvider、stock、weaponProgress，加小型目标目录、纯查询和可选个人声明。界面沿用深色进度终端，顶部紧凑目标列表、中央当前卡点与一条明确动作，攻略作为按需展开的操作轨迹。

## 状态与权威

- 目录新增GoalDefinition（stable id、标题、weaponId或factId、关联树节点），目标只4项：毒囊整体养成、大嘴安装、用户原称模块安装、海波整体养成。1999为单独手工摘要。
- Profile可选goalStates记录focused/done/deferred；可选personalFacts保存boolean/number/null、记录时间、用户原称及可选实体关联。整体目标done是用户声明，不填写weaponProgress各分项。weaponProgress仍是具体武器事实唯一权威；stock仍是库存唯一权威。旧档缺字段纯读为未知，不初始化写入。
- 纯evaluateGoal只依ID/结构查询。完成/暂缓排除待办；指定阶段直接提示操作，允许前序未知；安装已知且未选阶段时提示核对当前挑战；安装未完成才评估已知物品/用量。未知与0分开。无获取资料时提示核对，不虚构制造材料。
- 原helminth节点含“安装并首次进入”等宽泛路线记录，不完全等于单项安装声明；不自动写旧status或步骤。树详情只读展示相关事实并跳转目标助手，助手可定位原节点，两页从同一personalFacts读取安装声明。其他宽泛节点仅相关查看，无完成映射。
- DB/schema均保持1（可选兼容字段），catalogVersion升级2026.10.18.1。保留未知ID、所有旧数据/原件，容量/深度/更新屏障不变。

## 本次草案与冲突

草案为显式按钮打开的本用户输入，不是新档默认值。选择目标档案和模块实体关联后读取revision，生成逐项before/after、冲突与勾选预览。非冲突默认选，冲突默认不选，逐项选择覆盖；全局确认后事务提交。取消/仅预览不写入。目标或关联改变须重新生成预览；revision改变拒绝并要求重新预览。

提议：大嘴/原称模块已安装，毒囊整体done，海波focused并仅currentStageId=IV，1999等级3，其他集团“进展中、数值未知”。不注入毒囊分项、海波I—III、账号MR或解锁信息。模块默认保留原称未关联，用户可明确确认候选Helminth执刑官源力石模块；不关联Helminth联结模块。

Repository新增独立事务方法：guard→检查重复操作/revision→保存并读回一致旧快照→纯应用已选patch→完整validate→profile+去重标记原子提交。备份失败/配额/结构错误/更新屏障/并发均回滚。重复确认同一目标不重复日志，但同草案可用于另档。UI通过App现有保存队列串行，切档/等待写入时禁确认，广播变化。
