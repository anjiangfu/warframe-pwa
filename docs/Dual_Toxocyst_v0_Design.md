# 毒囊双枪养成助手 v0：设计与实施计划

2026-10-17。用户在来源聊天明确要求“先跑一个毒囊双枪”，本次作为独立单武器样例，覆盖旧M0停止点但不扩展M0自动返修授权。基线0827042ce31bffb4638abe2a8b4cad9d18b8c3e7，分支m1a/dual-toxocyst-pilot，原工作区干净。

## 最小闭环和方案

新增“养成助手”页面，沿用深色星图与青绿色操作，增加酸绿色武器标识和纵向I—IV任务轨迹。全部任务可展开，当前阶段仅为手工记录及下一步提示，不锁定后续查看/完成。各任务分开显示条件、前检、3—5条建议、地点模式、排查、证据等级和日期。三材料按钮进入同页详情，支持中文/英文搜索；未知持有量无精确缺口，已知0正常显示数量差。材料不足不阻止手工声明安装，不自动扣减或推断账号状态。

方案比较：不单独建一套武器档案/库存（避免重复事实），不升级整个DB/备份schema（无必要且增加M0迁移风险），采用可选字段的向后兼容扩展。

## 契约

- LocalProvider增加getWeaponCatalog()，版本化静态JSON包含weaponId、stageId、materialId、acquisitionId、来源表；UI不直接依赖第三方格式。原树目录ID/布局/状态不改，目录版本更新为2026.10.17.1。
- ProfileDocument增加可选weaponProgress字典，每武器含owned、adapterOwned、installed三态boolean|null、currentStageId:string|null和stages按stable stageId记录unknown/todo/progress/done。缺字段通过纯读取适配返回未知，不在打开档案/旧备份预览时自动写库；首次手动修改才保存完整该武器条目。重复适配幂等，不从旧29节点推断。
- 库存唯一权威仍是stock。旧credits/endo/forma/platinum保持原ID与数值；新增material:pathos-clamp、material:yao-shrub、material:eevani只在用户填写时落盘。缺key和null均未知，显式0保留，材料页和档案页读写同一stock值。
- DB_VERSION=1、schemaVersion=1保持，新增字段可选并受共享validateProfile校验；旧schema1/v1格式分别沿用原解析，旧档全部业务字段保持，新字段完整导出/导入。旧原件不改，8 MiB文件/业务负载8 MiB减2 KiB/深度20/50,000值约束仍适用。非法新状态、冲突、配额失败均无写入，所有页面经Repository和已有队列/更新屏障。
- 不新增联网、推荐评分或自动扣材料；当前周轮换不显示，不新增付费入口。没有图片/地图素材或第三方攻略拷贝。
